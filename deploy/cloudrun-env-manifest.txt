# Cloud Run service environment — the authoritative list of variable NAMES.
#
# WHY THIS FILE EXISTS
# cloudbuild.yaml deploys with `--set-env-vars`, which REPLACES the service's
# entire environment on every push to main rather than merging into it. A name
# dropped from that one line is deleted from production silently, and nothing
# in the app fails loudly — auth degrades, mail stops, the report surface falls
# back a rung. That happened on 2026-08-31 (12 minutes of production with no
# AUTH_SECRET/SMTP/GCS) and it had a latent twin: cloudbuild.yaml carried only
# 13 of the 16 names the live service was actually running.
#
# src/cloudbuild.contract.test.ts compares this list against the deploy line in
# cloudbuild.yaml on every CI run and fails when they disagree in either
# direction. Adding a variable to the service means adding it in BOTH places.
#
# NAMES ONLY. Never record a value here — several of these are secrets, and
# this file is public.
